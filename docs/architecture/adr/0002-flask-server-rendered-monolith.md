# ADR-0002: Монолітний Flask-застосунок із серверним рендерингом

- Статус: Accepted
- Дата: 2025-12-03 (перший коміт репозиторію)
- Власник: Denys Brenkach

## Контекст
Навчальна система з невеликою командою (один розробник), потрібні CRUD-форми, ролі та кілька JSON-ендпоінтів для приватності. Є вимога швидко ітерувати протягом семестру.

## Розглянуті альтернативи
1. **SPA (React) + окремий REST-бекенд (FastAPI)**: гнучкий інтерфейс, але два проєкти, два конвеєри збірки та більше інфраструктури для одного розробника.
2. **Django**: багато готового (адмінка, автентифікація), але вища вхідна складність і менше контролю над власною моделлю доступу.
3. **Flask + Jinja2 монолітом (обрано)**: мінімум рухомих частин, форми рендеряться на сервері, JSON API додається точково.

## Рішення
Один Flask-застосунок: сторінки рендеряться шаблонами Jinja2 (`templates/`), логіка приватності винесена в окремі модулі з JSON API (`/api/...`).

## Наслідки
- Плюси: один контейнер застосунку, проста збірка, швидкий старт нового розробника.
- Мінуси: `routes.py` розростається (кілька функцій у whitelist складності), інтерфейс не оновлюється без перезавантаження сторінки.
