# ADR-0001: PostgreSQL як сховище даних

- Статус: Accepted
- Дата: 2026-09-16 (за першим комітом `docker-compose.yml`; репозиторій створено 2025-12-03)
- Власник: Denys Brenkach

## Контекст
Система зберігає зв'язані дані: господарства, продукцію, працівників, користувачів, згоди. Потрібні зовнішні ключі, транзакції (анонімізація виконується атомарно) і запуск у контейнері.

## Розглянуті альтернативи
1. **SQLite**: нуль налаштувань, але один файл без конкурентного запису і з обмеженою підтримкою зміни схеми; погано підходить для контейнерів і кількох процесів.
2. **MongoDB**: гнучка схема, але дані системи реляційні (десятки зв'язків), а транзакційні гарантії та JOIN потрібні для звітів.
3. **PostgreSQL 15 (обрано)**: повноцінні FK і транзакції, офіційний alpine-образ, пряма підтримка в SQLAlchemy.

## Рішення
Використовувати PostgreSQL 15 у контейнері `postgres:15-alpine` з постійним томом, драйвер `pg8000`, доступ через Flask-SQLAlchemy.

## Наслідки
- Плюси: цілісність даних, атомарна анонімізація, відтворюване середовище.
- Мінуси: потрібен окремий контейнер, backup-процедури та керування схемою (міграцій поки немає, див. ISD R4).
