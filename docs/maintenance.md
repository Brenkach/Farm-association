# Регламент підтримки документації (Documentation Maintenance Regime)

## Правило
**Зміна коду = зміна документації.** Жодне злиття в основну гілку не проходить, якщо зачеплені документи не оновлено. Нове публічне API оновлює SDD §5, зміна розгортання або CI оновлює ISD, зміна призначення чи запуску оновлює README, нове рішення отримує новий ADR (старе позначається `Superseded`, а не переписується).
